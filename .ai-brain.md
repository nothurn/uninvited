## ★ Reconstruction base: hybrid — 1.20.1 for architecture, 1.21.1 for one supplementary data pool

This mod resolves RECOVERY.md section 4's open question ("Unklar, ob das
veröffentlichte Uninvited-Jar den migrierten oder den Vor-Migrations-Stand
enthält") — the two decompiled builds are genuinely different architectures,
not just an API-version difference:

- `B:\Claude\Projekte\_RECOVERY\decompiled\phantomjoin-forge-1.20.1\` —
  **the migrated version.** Mandatory `hauntedcore` dependency, no own name
  pool, subscribes to hauntedcore's `PresenceEndEvent` directly. **Use this
  as the base for the identity/architecture layer** — it reflects the
  intended final design (shared `FakeIdentity` via hauntedcore), not the
  older self-contained approach.
- `B:\Claude\Projekte\_RECOVERY\decompiled\phantomjoin-neoforge-1.21.1\` —
  the pre-migration version (this is what's actually live on Modrinth right
  now). No hauntedcore dependency. Has its own `PhantomJoinNames.java` — a
  self-contained pool with both realistic first names (matching
  hauntedcore's own `FakeIdentity.LOOKALIKES` list closely) **and** a second
  half of fake system-generated username patterns (`Player_%d`, `Guest_%d`,
  `User_%d`, `Account_%d`, `Unknown_%d`, `temp_user_%d`, `test_%d`,
  `NewPlayer%d`, `guest%d`, `Player%d`) that RECOVERY.md never mentions at
  all.

**When reconstructing: base the identity/architecture layer on the 1.20.1
(hauntedcore-migrated) source, but carry over the 1.21.1 build's
`PhantomJoinNames` system-pattern half as supplementary flavor data** — it's
real, undocumented content that would otherwise be lost once the
hauntedcore-based identity replaces the standalone name pool. Don't just
discard it because the architecture it originally lived in is being dropped.

**Sequencing:** copy the 1.20.1 source in first (architecture + API is
already Forge-1.20.1-shaped, needs porting to 1.21.1/NeoForge same as the
other mods — see RECOVERY.md section 8), then separately fold in the
system-pattern name list from the 1.21.1 build as extra data, not as a
replacement for `FakeIdentity`.
